## 🚀 Featured Projects

### 🧬 CSX-PCOSNet — Multimodal AI for PCOS Detection

> **Multimodal Contrastive Learning for Detection of Polycystic Ovarian Syndrome**

A research-oriented AI system that combines **clinical tabular data and ultrasound images** for PCOS detection.

**Highlights:**

* 🧠 Multimodal learning combining clinical and image modalities
* 👁️ CNN/CaiT-based image representation learning
* 📊 Self-attentive tabular feature learning
* 🔗 Cross-modal representation alignment
* ⚡ Contrastive learning with projection heads
* 🔀 Multimodal feature fusion
* 🧪 Experimentation with EfficientNet, VGG16, MobileNetV2, ResNet50 and InceptionV3
* 🔬 Implemented using **PyTorch + TensorFlow/Keras**

**Tech:** `Python` `PyTorch` `TensorFlow` `Keras` `OpenCV` `Computer Vision` `Deep Learning` `Contrastive Learning`
